# **Sistema Bancário**

## 🔍 Objetivo
  Esse é o projeto de Sistema Bancário desenvolvido por mim referente a atividade proposta no Bootcamp da DIO.
  Cada fase do Desafio foi composta por um avanço da complexidade envolvida.

## 📝 Linguagem

[Python](https://www.python.org/)

## 🗂️ Fases do Desafio
  Na primeira fase do desafio ([desafio_sistema_bancario.py](https://github.com/Dennis-Albarello/sistema_bancario/blob/develop/desafio_sistema_bancario.py)) tivemos a utilização de estruturas de repetição como o While e estruturas condicionais visando a utilização de um menu simples que executasse algumas operações simples relacionadas a Depositar, Sacar, verificar Extrato e Sair do Menu.  
  Na segunda fase do desafio ([desafio_sistema_bancario_02.py](https://github.com/Dennis-Albarello/sistema_bancario/blob/develop/desafio_sistema_bancario_02.py)) além das estruturas já utilizadas no primeiro desafio avançamos no desenvolvimento. Foram utilizadas estruturas de dados como Listas e Funções para desempenhar o funcionamento e execução dos itens do menu.  
  Na terceira fase do desafio ([desafio_ssistema_bancario_03.py](https://github.com/Dennis-Albarello/sistema_bancario/blob/develop/desafio_sistema_bancario_03.py)) utilizando-se dos conceitos de Programação Orientada a Objetos, tivemos a modelagem do sistema com a utilização de Classes e Objetos de Classes.
